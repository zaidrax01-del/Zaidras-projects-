How this is wired in production

  1. Backend calls the licensed on-ramp API → gets a per-user address + reference.
  2. Address and reference are shown to the user; nothing is hardcoded.
  3. Processor webhook hits /webhooks/crypto → matched by reference.
  4. Source-of-funds + sanctions screening runs before crediting.
  5. Only then is the ledger updated, with an immutable audit entry.
